# Exercice Revert

## Créer un nouveau dépôt

Cloner la branch du dépôt git contenant le corrigé de l'exercice précédent à l'aide de la commande suivante :

`git clone -b 05-revert https://github.com/ConveyCode/git-exercices.git 05-revert`

## Revert de contact

Revert tous les commits qui touchent au fichier contact.yaml pour supprimer le fichier du repo.
On ne doit pas faire un commit de suppression manuel mais utiliser la fonctionnalité "git revert" sur les commits présents dans l'historique.
